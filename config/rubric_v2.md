# 採点基準 v2.1(案。まだ本番では使わない。本番は config/rubric.md)

回の文字起こしを読み、**点ではなく、観察を出す**。観察は、「分」と「文字起こしからの引用」を必ず付けた1件ずつの記録。
点はコード(`neochi/observe.py`、数値は `config/observe.yaml`)が、観察の数から計算する。AIに点や★を書かせない。

問いは「**聞きながら眠れるか**」。聞き終えたあとの余韻ではなく、聞いている最中に、気持ちや頭を昂らせるか(🌊)、注意をほどよく占めるか(🎯)を見る。
定義の根拠は `docs/EVIDENCE.md`。

## 共通の決まり

- 文字起こしは回の冒頭から最大20分。`[n分]` の目印がある。冒頭の広告やお知らせは数えない。
- **1件ごとに、分(`min`)と、文字起こしのままの引用(`quote`、40字以内)を必ず付ける。引用できないものは数えない。**
- ジャンルや番組名で決めない。声の大きさ、話す速さ、音響(BGM・物音)は数えない(🎧で別に測る)。誤変換は、意味が取れる範囲で読む。
- 同じ話題が続く間は1件。1分以上あいて、また起きたら別の1件。
- **定義に当てはまるものは、見落とさず挙げる。** 引用で確かめられるものだけを挙げる(引用できないものは挙げない)。程度が小さくても、定義に当てはまれば挙げる(`strength` 1、または短い区間)。
- 穏やかな回でも、冒頭20分に、数件の観察があるのがふつう。観察が1つもない(空にする)前に、冒頭から読み直して、下の「見つけるときの目印」に当てはまる箇所がないかを、もう一度確かめる。
- 一方で、定義の「数えないもの」に当てはまるものは、挙げない。

## 🌊 起伏(気持ちや頭を昂らせる要素)

### emotion: 感情の昂り

| `kind` | 1件の条件 | 数えないもの |
|---|---|---|
| `negative` | 不安・恐怖・怒り・悲しみ・緊迫を、話し手が言葉で表す(「怖い」「許せない」)か、聞き手がそう感じる出来事(事件、事故、大きなけが、死、怪談)を具体的に語る | 穏やかな好き嫌い、軽い「へえ」、昔の思い出として淡々と語る話 |
| `conflict` | 2人以上(話し手どうし、または話の中の人物)が、敵意や圧力をもって対立する(口論、非難、詰問、論争) | **ツッコミ**(敵意がなく、笑いのため)。穏やかな意見の違い |
| `excitement` | はしゃぎ・熱狂・大声の盛り上がり(歓声、絶叫、興奮した早口の掛け合い) | **穏やかな楽しさ、軽い笑い、ほほえましい話**(これらは数えない) |

- `strength`: 1 = 一言や短いやりとり(およそ30秒未満)。2 = 30秒以上続く、または場面として具体的に語られる。
- 根拠の強さは `negative` と `conflict` が ◯、`excitement` は推論。点への効きは、`excitement` を小さくしてある。

### worry: 心配の種

聞き手が**自分ごととして考え込みそうな話題**を、具体的に扱っている箇所。
- `topic`: `health`(健康・体調) / `money`(お金・生活) / `work`(仕事・人間関係) / `incident`(事件・事故・災害) / `future`(将来の不安) / `other`
- 数えるもの: 話題を具体的に扱う(数字、固有の出来事、「こうなったらどうしよう」)。
- 数えないもの: 話題への一言の言及、他人事として笑える失敗談。

### load: 頭の負荷が高い区間

理解するのに、頭を使い続けないといけない区間。`from` / `to`(分)で区間を書く。
- 数えるもの: 数字・固有名詞・専門用語が、次々に出てくる。論理や因果の積み重ねを、追わないと分からない(解説、議論、ニュースの読み上げ、制度や仕組みの説明、歴史の経緯)。
- 数えないもの: 専門用語が1つ出るだけ、人名や作品名が出るだけの雑談、物語の登場人物の名前、**朗読の文語や古い言い回し**(語彙が難しくても、筋を追う負荷は低い)。

### 見つけるときの目印(これだけに限らない。意味で判断する)

- `negative`: 「怖い」「不安」「腹が立つ」「悲しい」「ひどい」「最悪」「許せない」「焦った」、事件・事故・災害・大きなけが・死・怪談・修羅場の話、深刻な失敗談。
- `conflict`: 「何言ってるんだ」「ふざけるな」「おかしいだろ」と詰める、責める、言い返す、互いに譲らない。ツッコミ(笑いのため)は除く。
- `excitement`: 「やばい」「ありえない」「うそでしょ」と声が上ずる、全員が笑い転げる、歓声や悲鳴、早口で畳みかける掛け合い。穏やかな笑いは除く。
- `worry`: お金の不安、体調や健康の心配、職場や家族の悩み、将来の不安、「どうしよう」「大丈夫かな」。
- `hook`: 「実は〜」「このあと〜」「答えは〜」「続きは〜」と引っぱる、結論を後ろに置く、謎や伏線を出す。
- `follow`: 「前回」「さっきの」「その人が」と、前の内容を前提にする、連続した物語。

## 🎯 程よい興味(注意を、穏やかに、ほどほどに占めるか)

「程よい」= **聞き流しても置いていかれず(hook と follow が少ない)、思い浮かべられる具体的な話が続いている(imagery がある)** 状態。

### hook: 先が気になる(未解決の問い)

謎・予告・「このあと〜」を出して、**5分以内に答えが出ない**もの。クリフハンガー、引っぱる予告。
- 数えないもの: 出してすぐ答える問い、聞き手への軽い呼びかけ。

### follow: 追い続ける必要

前の内容を覚えていないと、次が分からない箇所。連続した筋(物語、続き物の解説、前の話を前提にした議論)。
- `from` / `to`(分)で区間を書いてよい。
- 数えないもの: 1話完結の雑談、どこから聞いても分かる話、お便りの1通ごとの話。

### imagery: 思い浮かぶ具体性

情景・物・人物の動きが、具体的に思い浮かぶ語りが続く区間。例: 場所の描写、料理の手順、旅の様子、物語の場面、体験談。
- `from` / `to`(分)で区間を書く。
- 数えないもの: 抽象的な議論や意見、相づち、雑談のつなぎ、同じ話の繰り返し、意味の薄いやりとり。
- **この区間が少ないことが、退屈側のしるし**。退屈すぎると、聴くのをやめてしまう(睡眠の研究ではなく、使われ方の理由)。

## 出力

次のJSONだけを返す。前置きや説明は付けない。★や合計は書かない。

```
{"version": 2,
 "emotion": [{"min": 3, "kind": "negative", "strength": 2, "quote": "文字起こしのまま40字以内"},
             {"min": 9, "kind": "excitement", "strength": 1, "quote": "..."}],
 "worry": [{"min": 5, "topic": "money", "quote": "..."}],
 "hook": [{"min": 2, "quote": "..."}],
 "follow": [{"from": 6, "to": 14, "quote": "..."}],
 "load": [{"from": 3, "to": 9, "quote": "..."}],
 "imagery": [{"from": 0, "to": 8, "quote": "..."}, {"from": 12, "to": 19, "quote": "..."}],
 "content_summary": "2〜3文、120字以内。結末や答えは書かない",
 "content_start": {"sec": 95, "anchor": "本編の最初の一言(40字以内)"},
 "reason": "全体の根拠を一行(丁寧語、60字以内、「！」は使わない、診断に見える言葉は使わない)"}
```

- 観察がないときは、空の配列にする(`"emotion": []`)。
- 1分ごとの起伏(`calm_per_min`)と、起伏の山(`moments`)は、`emotion` と `worry` の観察から、コードが作る。書かない。
- `content_summary` と `content_start` の決まりは、`config/rubric.md` と同じ。
