# バックログ(MVP のあとに回すもの)

## 昼寝への対応

MVP は「夜に寝る」ことだけを前提にする。昼寝は考慮しない。

決まっていること:
- 睡眠は、時間帯ではなく、ヘルスケアの実測(再生開始以降に最初に「眠っている」と記録された時刻)で判定する。昼寝でも同じ仕組みで測れる。
- 昼寝を夜と分ける区分は作らない。同じ記録として扱う。

やること:
- 昼寝のあとの画面の言葉を直す。「昨夜の結果」「朝の振り返り」が夜前提になっている。
- 昼寝の再生が、就寝時間帯(`BedtimeWindow`)の計算や「昨夜の結果」に混ざらないようにする。
- 「どのくらい寝たか」を記録や評価に使うかを決める。今は入眠までの分数だけ。ヘルスケア側の方針として、睡眠の評価はしない。

## 就寝時間帯での夜の画面の自動表示

`BedtimeWindow`(NeochiCore)はあるが、アプリ側につながっていない。就寝時間帯にアプリを開いたら、夜の画面を出す。初回に就寝時刻を聞く画面も、まだない。
