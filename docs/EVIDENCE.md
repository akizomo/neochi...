# 採点の根拠の台帳(2026-11-16。採点と説明ページに反映済み)

利用者向けの説明は、サイトの「スコアと根拠」(`neochi/explainer.py`)。この台帳が正で、説明ページはここから作る。採点の決まりは `docs/SCORE.md` §2b。

採点のパラメータごとに「何を測る → どう点にする → なぜ(出典と強さ)」を書く。画面の「どのような根拠で評価しているか」は、ここから引く。
確定したら SCORE.md に取り込む。出典は検索で確かめた範囲で書き、原典の全文を読めていないものは「要原典確認」と付ける。

## 強さの記号

| 記号 | 意味 |

| ◎ | 睡眠を測った実験が、複数ある |
| ◯ | 睡眠を測った研究があるが、条件が Neochi と違う(自分の考えごと・環境騒音など)。そこからの推論 |
| △ | 睡眠を測った研究がない(睡眠以外の研究、理論だけ、社内データ) |

## 大前提で分かったこと(重要)

- **「聞く内容を選ぶと入眠が早まる」こと自体の証拠は弱い。**
  - 音楽: Cochrane レビュー(Jespersen ほか 2022、13試験・1007人)では、自己申告の入眠時間はわずかに改善する可能性がある(確実性は低い)。客観的な測定(3試験)では改善しない可能性がある。
  - 寝落ち用の物語: 495人の多群 RCT(USleep、Sleep 誌 2026)がある。効果量 0.12 で有意差なしという要約は二次情報なので、要原典確認。
  - 寝る前のメディア: 内容の昂りが入眠を遅らせる効果は、実験では小さいか、一貫しない。クリフハンガーの実験では、逆向きの小さな効果だった。
- **したがって、評点は「眠りを妨げる要素が少ない」ことを示す推定であり、「眠れる」ことの証明ではない。** 画面の言葉もこの範囲に留める(VOICE.md の「約束しない」と一致)。最終的な裏付けは、ヘルスケアの実測で取る。

## ここから言えること(方針の案)

1. **評点を動かす力を、根拠の強さに合わせる。** ◯ の項目(🌊 A・B・C、🎯 D、🎧 突発音・音量の変化)が評点の大半を決め、△ の項目は小さく効かせるだけにする。いまは △ の話す速さが 🎧 の 3割を占め、🎯 ゾーン(△)は 1 軸ぶん(0.3)を丸ごと動かせる。
2. **根拠、とくに出典は、番組や話の画面に出さず、「スコアと根拠」の説明ページにまとめる**(2026-11-16 の決定)。
   - 番組・話の画面: 「この話で何が見つかったか」(測った値、項目の点)だけ。いまの「観点ごとの根拠」の情報量は増やさない。出典や「研究がある/仮説」の注記も、画面には出さない。
   - 説明ページ: 「なぜそれで採点するのか」。この台帳から、観点・項目ごとに、測るもの、点の付け方、出典、根拠の強さを載せる。「聞く内容で眠れることの証拠はまだ弱く、評点は妨げる要素の少なさの推定」という前提も、ここに書く。
   - 入口: サイトの「解析について」を、このページにする。アプリは ⓘ からこのページへ。
3. **差をつけるのは格付けの線(方針)で行い、採点の数値を差のために動かさない。**
4. **実測(ヘルスケア)で確かめる。** 根拠の弱い項目ほど、実測で残すか外すかを決める。
5. **見直す:** 実測点の換算(10分 / 40分)を Ohayon に合わせて 15分 / 60分 にするか。

## 判定基準 v2(案): 観点と根拠(2026-11-19)

いまの🌊4項目と🎯5項目は、根拠から選んだ要素ではなく、先に感覚で決めてから、あとで根拠を当てはめたもの(`7463f8c` → 台帳 `b0edc97`)。そのため、根拠のない項目(急な転換、驚き、笑い、聞き手への働きかけ)が残り、満点が出やすく、判定者によるぶれも大きい。
v2 は、眠りを妨げる仕組みから観点を選び直す。枠は、入眠前覚醒尺度(Nicassio ほか 1985、*Behav Res Ther* 23:263-271)の「頭の昂り」と「体の昂り」。これは寝る人の状態を測る質問紙で、番組の内容を分類する根拠ではなく、**整理の枠として借りている**。頭の昂りを🌊と🎯、体の昂りを🎧が受け持つ。
定義は `config/rubric_v2.md`、点の計算は `neochi/observe.py`(数値は `config/observe.yaml`、仮)。AIに点を書かせず、**分と引用つきの観察を出させ、点はコードが計算する**。

### 🌊 起伏

| 観点 | 根拠 | 強さ |
|---|---|---|
| emotion: negative / conflict(不安・恐怖・怒り・悲しみ・緊迫、敵意のある対立) | 感情を起こす実験31本のメタ分析で、ネガティブな感情が入眠を遅らせた(Krizan ほか 2024) | ◯ |
| emotion: excitement(はしゃぎ・熱狂。穏やかな楽しさは数えない) | 寝る前のポジティブな感情の影響は、一貫したデータがない(*Sleep and affect: a conceptual review* 2022)。穏やかで前向きな読書は、高齢者の入眠を早めた(Sella ほか 2023、要原典確認)。高い興奮の楽しさだけを操作した研究は見つからない。点への効きは小さくし、実測で確かめる | △ |
| worry(聞き手が自分ごととして考え込みそうな話題) | 心配・反すうが入眠を遅らせる(Gross & Borkovec 1982、Zoccola ほか 2009)。ただし「自分の心配」で、聞いた内容から心配が生まれるかは推論 | ◯(推論) |
| 頭の負荷(数字・専門用語の密度。機械で数える) | Wuyts ほか 2012 | ◯(推論) |
| 急な転換 | 根拠なし。v2 では点に入れない(`textfeatures` に、記録だけ残す余地) | 外す |

### 🎯 程よい興味

「程よい」= 聞き流しても置いていかれず(hook と follow が少ない)、思い浮かぶ具体的な話が続いている(imagery)状態。

| 観点 | 根拠 | 強さ |
|---|---|---|
| imagery(思い浮かぶ具体性)。**少ないほど退屈側** | 不眠の人41人で、情景を思い浮かべる気そらしが、何も指示しない群より自己申告の入眠を早めた。「考えごとに戻らない頭の余地を占める」という説明(Harvey & Payne 2002、*Behav Res Ther* 40:267-277)。退屈そのものと入眠の研究は見つからない。退屈側の減点は、仮説と、使われ方の理由(退屈だと聴くのをやめる)による | ◯(推論)+ 使われ方 |
| follow(追い続ける必要) | 頭の負荷(Wuyts ほか 2012)からの推論 | △〜◯ |
| hook(先が気になる) | 直接の実験は、**逆の結果**。サスペンスのドラマを3〜4話見ると、入眠は早まった。クリフハンガーで終わると、心拍・コルチゾールが上がり、深い睡眠が減った(Baselgia ほか 2023、*Sleep Med* 102:186-198、50人。見終わってから寝る条件で、聴きながらではない)。注意が狭まる研究(Bezdek ほか 2015)は、睡眠を測っていない。減点は小さくして残し、実測で確かめる | △ |
| 驚き・笑い・聞き手への働きかけ | 根拠なし。v2 では点に入れない。笑いは、音声から測る候補(🎧、笑い声の検知。検知の精度は未確認) | 外す |

### このレビューの限界

PubMed や論文 PDF に接続できない環境だったので、確認は、要旨と、それを引いた文献までで、本文の数値は読んでいない(「要原典確認」)。根拠のほとんどは、「自分の考えごと」や「自分で行う作業」の研究で、「聞く内容」を直接調べた研究は、ほぼない。効果の大きさも、数分の単位。どの観点も、最後はヘルスケアの実測で確かめる前提。
