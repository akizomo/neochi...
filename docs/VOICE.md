# ボイス＆トーン（NeochiPickzz の言葉の決まり）

アプリ・スコアカード・X投稿・説明ページの文言は、この文書を正とする。
表示文字列の置き場は `neochi/strings.py`（解析・カード）と `ios/Sources/NeochiCore/Strings.swift`（アプリ）。
スコアの用語の定義は `docs/SCORE.md`。食い違ったら、用語は SCORE.md、言い方はこの文書に合わせる。

状態: 確定（2026-11-14）。変えるときは、この文書を先に直す。

---

## 1. 名前と人格

**名前は NeochiPickzz**。スペースを入れない一語で、大文字は N と P だけ。文章、ストア、SNS でもこの表記にし、カタカナ表記は使わない。「寝落ちスコア」は仕組み全体の呼び名で、プロダクト名としては使わない。


**深夜ラジオの小声で、淡々と測る人。**

道具に近い（Siriくらいの距離）。友だちでも先生でもない。測った結果を、静かに読み上げる。
一人称（わたし）も二人称（あなた）も出さない。主語を出さずに、事実だけを言う。

## 2. ボイスチャート

ボイスはいつも同じ。3つの特徴でできている。

| | 1. 淡々と測る | 2. 小声で、押しつけない | 3. 真顔で、少しずれる |
| --- | --- | --- | --- |
| **ひとことで** | 気持ちではなく、数字と事実で言う | 眠りかけの人の邪魔をしない | 冗談は言うが、顔は真面目なまま |
| **こういう声** | 観測記録、天気予報、気象通報 | 深夜ラジオのパーソナリティの小声 | 細かすぎる数字を、当然のように言う |
| **こういう声ではない** | 感想、褒め言葉、盛り上げ | 励まし、説教、急かし、通知で起こす | ボケて笑わせにいく、ふざけた顔、ネットスラング |
| **言葉** | 分、件、回、評点、推定、実測 | です・ます。短い文 | 番組のせいにする言い回し（「番組の力ではなく」） |
| **文の形** | 結論が先。数字は文の頭に近く | 1文は40字まで。1画面に文は3つまで | ずれは文末の一言だけ。前半は普通に言う |
| **使わない** | すごい、最高、ぴったり、おすすめです | 〜しましょう、〜してください（説明・操作以外）、早く寝ましょう | 「！」「w」「笑」、顔文字 |
| **例 ○** | 本日の寝落ち、14分。 | 答えなくても記録できます。 | それは番組の力ではなく、ただの寝不足です |
| **例 ×** | 今夜はよく眠れましたね！ | 毎晩記録して、睡眠を整えましょう | 秒で寝落ちｗ 最強番組すぎる |

配分の目安: **事実9割、ずれ1割。** ずれは無くても成り立つ。迷ったら、ずれを削る。

## 3. トーン（場面ごとの調整）

ボイスは変えず、場面に合わせて「ずれ」と「長さ」を調整する。ずれは 0（なし）〜2（あり）で表す。

| 場面 | 相手の状態 | ずれ | 長さ | こう書く | 例 |
| --- | --- | --- | --- | --- | --- |
| 昼（見つける・一覧・詳細） | 起きている。比べたい | 1 | 短い説明は1〜2行 | 番組の特徴を、観測の言葉で書く | 声がゆっくりで、音量の変化が小さい番組です |
| 夜（今夜・再生中） | 眠りかけ | 0 | 単語か1文 | 操作の名前だけ。説明しない | 今夜聴く／一時停止／終わる |
| 朝（結果） | 起きたばかり | 2 | 1文＋一言 | 決まり文句で結果を読み上げる | 本日の寝落ち、14分。理想の寝落ちでした |
| 朝（振り返りの質問） | 起きたばかり | 0 | 1問1文 | 答えやすい問いにする。任意だと伝える | この話は、どうでしたか |
| 説明（ⓘ・根拠・解析について） | 理由を知りたい | 0 | 1〜2行。根拠の強さは◎◯△ | 誇張しない。仮説は仮説と書く | 冒頭を文字起こしして判定しています。 |
| 空の状態 | 何もない | 1 | 1文 | 何もないことを、そのまま言う | まだ記録がありません。 |
| 待ち・確認中 | 待っている | 1 | 1文 | 何を待っているかを言う | 寝落ちの記録を確認中です |
| エラー・権限・プライバシー | 困っている、不安 | 0 | 1〜2文 | 何が起きたか、どうすればいいかを普通に言う | ヘルスケアの読み取りが許可されていません。設定から変えられます。 |
| X投稿・スコアカード | 流し見している | 2 | カード＋2〜4行 | 実験記録の体裁。結果を淡々と報告 | Day 12。本日の寝落ち、42分。最後まで聴いてしまいました |

**ずれを入れていい場所:** 結果のコメント、空の状態、見本データの番組名、X投稿、スコアカード。
**ずれを入れない場所:** 夜の画面、エラー、権限、プライバシー、ヘルスケアの説明、お金、根拠の説明。

## 4. ずれ方の型

ずれは、この3つの型からだけ出す。新しい型を足すときは、この表に足す。

| 型 | やり方 | 例 |
| --- | --- | --- |
| 観測・予報の言い回し | 寝落ちを天気や観測記録のように言う | 波浪注意報が出ています（起伏 2.0未満）／計算どおりでした |
| 細かすぎる精度 | どうでもいいところだけ、真面目に測る | 笑い声、3回。うち1回は許容範囲 |
| 番組に責任を寄せる | 結果を人ではなく番組のせいにする | 最後まで聴いてしまいました／それは番組の力ではなく、ただの寝不足です |

**やってはいけないずれ:**
- 人の睡眠や体調をからかう（「また夜更かしですか」）
- 健康・診断・効能に触れる
- 特定の番組や出演者を下げる（「つまらないので眠れます」）。退屈も「程よい興味」の言葉で言う

## 5. 言葉の決まり（用語集）

| 使う | 使わない | 決まり |
| --- | --- | --- |
| 聴く | 聞く | すべて「聴く」に揃える（今夜聴く、聴いた話、最後まで聴いてしまいました）。例外なし |
| NeochiPickzz | neochi…、Neochi PickZz、カタカナ表記 | 名前は一語。カタカナにしない |
| 番組／話 | エピソード、回、コンテンツ | 番組＝シリーズ全体、話＝1本（2026-11-16 に「回」から変更。「回」は、数えるときだけ使う：○回目、突発音○回）。「このコンテンツの評価」は「この話の評価」に直す |
| 寝落ち | 入眠（文中） | 画面の文章は「寝落ち」。データのラベルだけ「入眠（推定）」を使ってよい |
| 寝落ちまで xx分 | 入眠潜時、スコア（結果に対して） | 分は整数。秒は出さない |
| 評点 | 寝落ち適性、スコア（画面で） | 画面に1つの点として出すのは総合評点。★の記号と数字で出す（例 ★ 4.3）。★は文字の記号で、絵文字の星は使わない。「寝落ちスコア」は仕組みの呼び名で、画面には出さない（2026-11-15 変更） |
| AI解析 | AIの見立て、AI判定 | 内訳の表記は「AI解析 4.1・みんな 3.8（52件）・寝落ちまで 平均14分（ヘルスケアの実測 8件）」。分は「再生を始めてから眠るまで」なので、「ヘルスケアの実測」だけでは何の時間か分からない。「寝落ちまで」を先に言う。あるものだけ並べる。みんなの評価は10件未満なら出さない |
| ヘルスケアの実測／自己申告 | 実測(ウォッチ)、ウォッチの実測、ウォッチで測った記録 | 表記を1つに揃える。ヘルスケアの睡眠データの「眠っている」から測る(ウォッチに限らない。2026-11-16) |
| 調査中 | 未評価、データなし | 実測がない番組 |
| 程よい興味／起伏の少なさ／耳のゆるさ | 面白さ、退屈度 | 3軸の名前は変えない |
| 退屈寄り／ちょうどよい／引き込まれすぎ | 静かめ／程よい／強め | 🎯(程よい興味)の3段階の言葉。**朝の振り返りのスライダーのゾーン名と同じ**にする(1〜3 / 4〜6 / 7〜10 と、一覧・詳細の言葉を、そろえる)。「静かめ」は、寝るのに良さそうに聞こえて、退屈側の意味と食い違うので、やめた(2026-11-20)。左右が対称で、真ん中が「ちょうどよい」と分かる言葉にする |
| 寝落ち格付け／Z・ZZ・ZZZ | 星、ランク◯位、圏外 | 総合評点で決める格付け。バッジは評点の数字の横に置かず、一覧と今夜のカードではカバー画像の右上、番組の詳細ではタイトルの上に置く。詳細では評点の下に内訳を必ず出す。基準未満の番組は、どこにも出さず、「圏外」とも書かない（検索では「まだ掲載していません」） |

**使わない言葉（テストで検査）:** 🥄、スプーン、不眠、障害、病気、症状、改善、治る、効果、効く、睡眠の質、科学的に証明、ゆったり、癒し。
追加（2026-11-14）: 快眠、熟睡、安眠、ぐっすり（睡眠を評価しているように見える）、最強、神回（盛り上げる言葉）。

## 6. 書き方の決まり

| 項目 | 決まり | 例 |
| --- | --- | --- |
| 文体 | です・ます。体言止めは結果の読み上げとラベルだけ | 本日の寝落ち、14分。 |
| 句点 | 文には「。」をつける。ボタン・ラベル・見出しにはつけない | 記録する／まだ記録がありません。 |
| 記号 | 「！」と三点リーダー「…」は使わない。「？」は全角 | ふだん、何時ごろ寝ますか？ |
| 数字 | 半角。単位は全角（分、件、回）。強調するのは数字だけ | 昨夜は**18分**で寝落ち |
| ボタン | 動詞で終える。2〜5文字 | 記録する／決める／終わる／あとで |
| 主語 | 出さない。「わたし」「あなた」は使わない | 昨夜は18分で寝落ち |
| 絵文字 | どこにも使わない（画面、スコアカード、X投稿、説明ページ）。記号が要るときは、デザインしたアイコンを使う。眠りは Z で表す | |
| 英語 | 画面は日本語。説明ページの英語の一文だけ英語 | Neochi (n.) — Japanese for drifting off mid-episode. NeochiPickzz picks what to drift off to. |

## 7. 決まり文句

何度も見てもらう型。言い回しを変えない。

| 場面 | 型 |
| --- | --- |
| 朝の結果 | 本日の寝落ち、{分}分。{コメント} |
| 結果がない朝 | 寝落ちまで ―　寝落ちの記録を確認中です |
| 今夜の理由 | 下の「今夜の理由」の表 |
| 朝の通知（案） | 昨夜の寝落ち、記録できました。 |
| X 毎日の投稿の1行目 | Day {n}。本日の寝落ち、{分}分。 |

今夜の理由（候補カードの上の1行。20字まで。切れないこと。句点はつけない。強調は数字だけ）:

| 理由 | 文 |
| --- | --- |
| 昨夜すぐ寝落ち | 昨夜は**{分}分**で寝落ち |
| 昨夜は時間がかかった | 昨夜は**{分}分**。次の話へ |
| 話の選び方 | 昨夜と同じ話／前に聴いた話／まだ聴いていない話／最新の話／ひとつ前の話 |
| 明日の、いまの番組 | いまの番組の続き |
| 次に聴くに入れた | 「次に聴く」に入れた番組 |
| お気に入りから | お気に入りの{系統}（系統名がなければ、お気に入りの番組） |
| 同じ系統の別番組 | 同じ{系統}の、別の番組（系統名がなければ、同じ系統の、別の番組） |
| 系統を変える | {系統}から、{系統}へ（系統名がなければ、ちがう系統の番組） |
| 同じ系統が続いた（2晩以上。晩数を数えられるときだけ） | {系統}が**{n}晩**。{系統}へ |

系統名（理由と絞り込みに出す名前）。`data/shows.csv` の genre 列に、この名前をそのまま入れる（2026-11-15）。
系統はアプリ独自の分け方。Apple Podcasts のカテゴリ（RSS の itunes:category）は apple_category 列に残し、系統の初期値に使うだけで、そのままは出さない。
番組を集めた目的（人気番組の一般枠、比較用、海外の基準）は cohort 列に分け、画面には出さない。

| 系統 | 入る番組 | 決め方 |
| --- | --- | --- |
| 寝落ち用 | 寝落ち・睡眠導入のために作られた番組（海外の番組も） | 手で決める。いちばん大事な系統なので、迷ったら入れない |
| 朗読 | 本や物語を読む番組 | 手で決める（Apple の Fiction は初期値で朗読） |
| 環境音 | 環境音・瞑想 | 手で決める |
| コメディ | 芸人やコメディの番組 | Apple の Comedy |
| 雑談 | トーク・雑談・カルチャー | Apple の Society & Culture、Leisure、Arts、TV & Film など |
| 教養 | 歴史・科学・仕事など、何かを解説する番組 | Apple の Education、History、Science、Business など |

- 見つけるでは、寝落ち用・朗読・環境音を「寝落ち用」の棚に、コメディ・雑談・教養を「寝落ち用ではないのに眠れる番組」の棚に入れる（2026-11-16）。朗読と環境音は、実質、寝落ち用として扱う。系統の名前は分けたまま。
- 系統を増やす、分けるときは、この表を先に直す。雑談か教養が大きくなって分けるときは、Apple の日本語の名前（歴史、科学、ニュース、事件／犯罪など）を使う。
- 番組を足したら `python -m neochi categorize` を流し、入った初期値を確かめて、寝落ち用・朗読・環境音は手で直す。

表にない値は、括弧と「・」を含まず6字までなら、そのまま系統名にする。それ以外は「なし」（名前を出さない）。
「1晩続いた」とは書かない。晩数を数えていないときは、晩数を出さない。

格付けバッジの横のひとこと（番組の詳細。基準の数字は出さない。ミシュランのように、その番組をどう勧めるかを言う）:
ZZZ「眠りたい夜は、まずこの番組」／ZZ「寝落ちのために選びたい番組」／Z「寝落ちに向いた番組」
「確実に眠れる」「必ず」のような約束はしない（効能の約束になる）。基準の数字（Z 3.6 以上、ZZ 4.1 以上、ZZZ 4.5 以上）は、「スコアと根拠」のページに書く。

結果のコメント（`docs/SCORE.md` §3 と同じ）:
10分未満「即落ちでした」／10〜20分「理想の寝落ちでした」／20〜30分「やや粘りました」／30分以上「最後まで聴いてしまいました」

## 9. 守らせる仕組み（実装のタスク）

- 画面の文言を `Strings.swift`（NCString）に集める。いまは `ios/App/Screens/*` に直書きが残っている
- `tests/test_strings.py` を広げる: Swift の文字列と `docs/` も検査する。「！」、半角「?」、絵文字、「聞く」、追加の使わない言葉を検査する
- Claude Code・スキル（neochi-designer / neochi-sns）への依頼では、最初にこの文書を読ませる
