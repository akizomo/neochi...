# スコアの仕組み(解析・DB・アプリ共通の定義)

スコアの定義は、この文書を正とする。数値の実体は `config/scoring.yaml` と `config/z_rank.yaml` にあり、変えるときは、この文書と同時に直す。
企画の背景は PRD(https://claude.ai/artifact/WBfoWA11jbKuP1AUC62PKb)。

## 1. いちばん大事な決まり: 要因と結果を混ぜない

| | 要因(番組の評価) | 結果(実際の睡眠) |
|---|---|---|
| 何を表すか | その回が、寝落ちに向いた作りか | その人が、何分で眠ったか |
| 記号 | 😴 寝落ち適性★(🎯 🌊 🎧 の3軸) | 🥄 寝落ちまでの分数、Zランク |
| どこに保存 | `analysis` | `sleep_log` |
| 誰が決める | AI解析 + みんなの評価 | Apple Watch の実測(watch)、自己申告(self) |

- ★に睡眠の結果(分数)を混ぜない。Zランクに★や主観を混ぜない。
- アプリの画面でも、「番組の評価」と「あなたの睡眠の結果」は、見出しを分けて出す。
- 睡眠の良し悪し(点数、睡眠段階、質)は評価しない。出すのは「再生してから眠るまでの分数」だけ。

## 2. 要因: 😴 寝落ち適性★(1〜5)

3つの軸を合わせた★。高いほど、寝落ちに向いた作り。

| 軸 | 意味 | ★の向き | 誰が判定 | 値 |
|---|---|---|---|---|
| 🎯 程よい興味 | 引き込む力が、ちょうどいいか | **真ん中が最良**(退屈でも、聴き入りすぎても落ちにくい) | AI(低/中/高)+ みんな | `interest_level`: low / mid / high |
| 🌊 起伏の少なさ | 感情の波、展開の引き、頭を使わせる度合いが少ないか | **★が多いほど起伏が少ない(良い)** | AI(文字起こしを読む)+ みんな | `calm_star`: 1〜5(0.5刻み) |
| 🎧 耳のゆるさ | 話す速さ、速さのばらつき、音量の変化、突発音 | ★が多いほどゆるい(良い) | 音響の計算だけ | `ear_star`: 1〜5 |

AI解析の総合(`total_star`):
```
🎯★ = low 3.0 / mid 5.0 / high 2.0
total = 🎯★×0.3 + 🌊★×0.4 + 🎧★×0.3   (欠けた軸は除いて重みを配り直す)
```

解析の範囲: 回の冒頭20分(0〜10分を×3、10〜20分を×2で重く見る)。入眠までの時間の目安(15分以内がよい、Ohayon ほか 2017)に合わせている。音量と突発音は全編で見る。

### 最終★(`final_star`、アプリに出す★)
```
みんなの評価が0件 → final = total(AI解析のみ)
n件あるとき       → w = min(0.5, n / (n + 10))
                    final = total×(1−w) + みんなの🌊★の平均×w
```
- AIとみんなの差が1★以上なら、`final_reason` に一行の説明が入る。
- 人の手で★を動かさない。
- 番組の★(`show.show_star`)は、その番組の回ごとの最終★の平均。

## 3. 結果: 🥄 寝落ちまでの分数と Zランク

`latency_min` = 入眠時刻 − 再生開始時刻(分単位。入眠判定はずれるので、秒は出さない)。

| 分数 | 表示コメント |
|---|---|
| 5分未満 | それは動画の力ではなく、ただの寝不足です |
| 5〜10分 | スプーン即落下 |
| 10〜20分 | 理想のスプーン |
| 20〜30分 | スプーン粘り気味 |
| 30分以上 | スプーン、朝まで握ってた |

Zランク(番組単位、掲載の目安): **実測(source=watch)だけ**で決める。30分未満を「寝落ちした」とみなす。

| ランク | 条件(仮) |
|---|---|
| Z | 30分未満が1件以上 |
| ZZ | 実測の半分以上が30分未満 |
| ZZZ | 8割以上が30分未満、かつ5件以上 |

## 4. 朝の振り返り: アプリで聞くことと、DBの値

| 質問(画面) | 何を聞くか | 選択肢 → DBの値 | 何に使うか |
|---|---|---|---|
| この回の話は、どうでしたか | 🎯 興味の程よさ。**3択** | 退屈だった → `interest_vote = -1` / ちょうどよかった → `0` / 聴き入った → `1` | 🎯 の「ちょうどいい」割合(将来、🎯★ = 1 + 4×割合) |
| 話の流れは、ゆるやかでしたか | 🌊 起伏の少なさ。**5段階、両端に言葉** | 1 = 起伏が多かった … 5 = ゆるやかだった → `calm_vote` | 最終★に混ぜる「みんなの🌊★」 |
| メモ | 自由記入 | `note` | 集計には使わない |

- 興味はスライダー(0〜100)にしない。DBの -1/0/1 と合わない(制約違反になる)うえ、「大きいほど良い」と読めてしまう。
- 起伏は「★が多いほど良い」と画面で分かるよう、両端に「起伏が多い」「ゆるやか」を置く。
- 分数(🥄)は聞かない。ヘルスケアの実測があれば `source=watch`、なければ自己申告で `source=self`。
- 現状、最終★に混ぜているのは `calm_vote` だけ。`interest_vote` は保存のみで、まだ★に入れていない。

## 5. 画面での言葉

- 「寝落ちスコア」は、この仕組み全体の呼び名(仮称)。画面に1つの「スコア」として出すのは、😴 最終★。
- 結果の分数には、「良い・悪い」ではなく、上の🥄のコメントを使う。
- 診断に見える言葉(不眠、改善、効果、治る など)は使わない。根拠は誇張しない。
- 点数の意味は、ⓘ から開く説明にまとめる(★の3軸、🥄、Z)。
