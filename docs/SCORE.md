# スコアの仕組み(解析・DB・アプリ共通の定義)

スコアの定義は、この文書を正とする。数値の実体は `config/scoring.yaml` と `config/z_rank.yaml` にあり、変えるときは、この文書と同時に直す。
企画の背景は PRD(https://claude.ai/artifact/WBfoWA11jbKuP1AUC62PKb)。

## 1. いちばん大事な決まり: 要因と結果を混ぜない

| | 要因(番組の評価) | 結果(実際の睡眠) |
|---|---|---|
| 何を表すか | その回が、寝落ちに向いた作りか | その人が、何分で眠ったか |
| 記号 | 😴 寝落ち適性★(🎯 🌊 🎧 の3軸) | 🥄 寝落ちまでの分数、Zランク |
| どこに保存 | `analysis` | `sleep_log` |
| 誰が決める | AI解析 + みんなの評価 | Apple Watch の実測(watch)、自己申告(self) |

- ★に睡眠の結果(分数)を混ぜない。Zランクに★や主観を混ぜない。
- アプリの画面でも、「番組の評価」と「あなたの睡眠の結果」は、見出しを分けて出す。
- 睡眠の良し悪し(点数、睡眠段階、質)は評価しない。出すのは「再生してから眠るまでの分数」だけ。

## 2. 要因: 😴 寝落ち適性★(1〜5)

3つの軸を合わせた★。高いほど、寝落ちに向いた作り。

| 軸 | 意味 | ★の向き | 誰が判定 | 値 |
|---|---|---|---|---|
| 🎯 程よい興味 | 続きを聞きたくなる力(引き込み力)が、ちょうどいいか | **真ん中が最良**(退屈すぎると雑念が戻り、引き込まれすぎると聞き続けてしまう) | AI(項目採点)+ みんな | `interest_score`: 1〜10、`interest_level`: low(1〜3)/ mid(4〜6)/ high(7〜10) |
| 🌊 起伏の少なさ | 気持ちや頭を昂らせる強さ(感情、対立、頭の負荷、急な転換)が少ないか | **★が多いほど起伏が少ない(良い)** | AI(項目採点)+ みんな | `calm_star`: 1〜5(0.5刻み) |
| 🎧 耳のゆるさ | 話す速さ、速さのばらつき、音量の変化、突発音 | ★が多いほどゆるい(良い) | 音響の計算だけ | `ear_star`: 1〜5 |

🎯 と 🌊 の採点は「聞きながら眠れるか」で見る。AIは項目ごとに 0/1/2 を付けるだけで、★はコードが計算する(項目は `config/rubric.md`)。

| 🎯 引き込み力の項目 | 🌊 起伏の項目 |
|---|---|
| A. 未解決の問い(謎、伏線、「この後」) | A. 感情の強さ(不安・恐怖・怒りは2まで、楽しい興奮は1まで) |
| B. 驚き・新しい情報 | B. 対立・緊張 |
| C. 笑い | C. 頭の負荷(数字・固有名詞・論理の密度) |
| D. 追い続ける必要(聞き逃すと分からなくなるか) | D. 急な転換 |
| E. 聞き手への働きかけ | |

```
引き込み力 = 🎯の項目の合計(0〜10。0 のときは 1)
🎯★ = 引き込み力 4〜6 で 5.0、1 で 3.0、10 で 1.0、その間は直線(ゾーンは仮説)
🌊★ = 5 − 🌊の項目の合計 × 0.5
total = 🎯★×0.3 + 🌊★×0.4 + 🎧★×0.3   (欠けた軸は除いて重みを配り直す)
```

根拠の強さ(◎ 実験の積み重ね / ◯ 関連研究・理論 / △ 仮説):
- 入眠には、認知処理・認知的な駆動・努力・感情の負荷が少ないことが望ましい、という考え方(Espie & Wicklow)◯
- 不安や心配ごとを増やすと入眠までの時間が延びる ◎(🌊 A・B)
- 入眠しようとしている間に、興味を引く穏やかな課題で頭を埋めると、入眠が早まる。単調すぎる課題(羊を数える)は効果が薄い(Harvey & Payne 2002)◯(🎯 のゾーン)
- 意味を組み立てる処理は眠りを妨げ、脈絡のない思考は眠りを促す、という理論(Beaudoin)◯(🎯 D、🌊 C)
- 緊張の高まる場面は、見聞きしている最中の注意を掴む(Bezdek ほか)◯(🎯 A。睡眠は測っていない)
- 笑い、聞き手への働きかけ、ゾーンの位置、点数の配分 △
- 「見終えてから寝る」条件の研究(サスペンスドラマの視聴後に寝る、など)は、「聞きながら寝る」Neochi とは条件が違うので、判断材料にしない

解析の範囲: 回の冒頭20分(0〜10分を×3、10〜20分を×2で重く見る)。入眠までの時間の目安(15分以内がよい、Ohayon ほか 2017)に合わせている。音量と突発音は全編で見る。

### 最終★(`final_star`、アプリに出す★)
```
みんなの評価が0件 → final = total(AI解析のみ)
n件あるとき       → w = min(0.5, n / (n + 10))
                    final = total×(1−w) + みんなの🌊★の平均×w
```
- AIとみんなの差が1★以上なら、`final_reason` に一行の説明が入る。
- 人の手で★を動かさない。
- 番組の★(`show.show_star`)は、その番組の回ごとの最終★の平均。

## 3. 結果: 🥄 寝落ちまでの分数と Zランク

`latency_min` = 入眠時刻 − 再生開始時刻(分単位。入眠判定はずれるので、秒は出さない)。

| 分数 | 表示コメント(モック・アプリと同じ) |
|---|---|
| 5分未満 | それは番組の力ではなく、ただの寝不足です |
| 5〜10分 | 即落ちでした |
| 10〜20分 | 理想の寝落ちでした |
| 20〜30分 | やや粘りました |
| 30分以上 | 最後まで聞いてしまいました |

Zランク(番組単位、掲載の目安): **実測(source=watch)だけ**で決める。30分未満を「寝落ちした」とみなす。

| ランク | 条件(仮) |
|---|---|
| Z | 30分未満が1件以上 |
| ZZ | 実測の半分以上が30分未満 |
| ZZZ | 8割以上が30分未満、かつ5件以上 |

## 4. 朝の振り返り: アプリで聞くことと、DBの値

入力は2つ + 任意のメモ。「記録する」を押したときだけ保存する(2026-11-13 の決定。以前の3択は廃止)。

| 画面の項目 | 入力 | DBの値 | 何に使うか |
|---|---|---|---|
| 興味 | スライダー。10段(0〜100の10刻み)で止まる。触るまで未入力 | `interest_vote`(0〜100、10刻み。migration 0003 で制約を置き換え済み) | 🎯 の「ちょうどいい」水準。将来、最終★に混ぜる |
| 起伏 | ★1〜5(同じ星をもう一度押すと未入力) | `calm_vote` | 最終★に混ぜる「みんなの🌊★」 |
| メモ | 自由記入(任意) | `note` | 集計には使わない |

- 分数(🥄)は聞かない。ヘルスケアの実測があれば `source=watch`、なければ自己申告で `source=self`。
- 睡眠のスコアや評価は出さない(入眠の時刻だけ)。
- 現状、最終★に混ぜているのは `calm_vote` だけ。`interest_vote` は保存のみ。

## 5. 画面での言葉

- 「寝落ちスコア」は、この仕組み全体の呼び名(仮称)。画面に1つの「スコア」として出すのは、😴 最終★。
- 結果の分数には、「良い・悪い」ではなく、上の🥄のコメントを使う。
- 診断に見える言葉(不眠、改善、効果、治る など)は使わない。根拠は誇張しない。
- 点数の意味は、ⓘ から開く説明にまとめる(★の3軸、🥄、Z)。

## 6. 分析の詳細(アプリで見せるデータ)

各回の `analysis` には、★だけでなく、根拠になったデータを保存する。アプリの番組・回の詳細で、項目ごとに見せる。

| 何を見せるか | 保存場所(`analysis` の列 → キー) | 単位・範囲 | 見せ方の案 |
|---|---|---|---|
| 🎧 の内訳★ | `features.ear_parts` → `rate` / `rate_cv` / `volume` / `sudden` | 各 1〜5 | 4項目の★を並べる(話す速さ / 速さのばらつき / 音量の変化 / 突発音) |
| 話す速さ | `features.speech_rate`(前半重み付き)、`features.timeline.rate_per_min` | 日本語は 字/分。冒頭20分のみ。発話が少ない分は null | 1分ごとの折れ線。満点の上限(290字/分)に線を引く |
| 速さのばらつき | `features.speech_rate_cv` | 0〜(0.10 で満点、0.40 で最低) | 数字は出さず、内訳★と一言で |
| 音量の変化 | `features.volume_std_db`、`features.timeline.volume_db` | 1分ごとの、回全体の中央値との差(dB)。全編。無音の分は null | 0 を中心にした折れ線。上下の幅が小さいほどゆるい |
| 突発音 | `features.sudden_per_10min`、`features.timeline.sudden_at_sec` | 回数/10分、起きた秒(最大300件)。全編 | 音量の折れ線の上に印 |
| 🌊🎯 の根拠 | `reasons.llm`、`interest_score`、`interest_level`、`calm_star` | 60字以内の一行 | 軸の★の下に一行 |
| 🌊🎯 の項目ごとの点 | `reasons.items.interest` / `reasons.items.calm` → 各項目 `{score: 0〜2, min: 分 or null}` | | 項目を並べ、1以上の項目は該当する分に印 |
| 目立つ箇所 | `reasons.moments` → `[{min, note}]`(最大3件) | 冒頭20分の中の分 | 🎧 のグラフの時間軸に、印と一言を重ねる |
| 解析の深さ | `input_depth` | audio = 音響のみ / transcript = 文字起こしあり / meta = 説明文のみ | 「どこまで解析したか」の注記 |
| 長さ | `features.duration_sec` | 秒 | |

注意:
- 話す速さは冒頭20分だけ、音量と突発音は全編。グラフの横軸の長さが違うので、同じ図に重ねるときは時間軸をそろえる。
- 突発音は、屋外の環境音や効果音の多い回で、多めに数えることがある。数値は「目安」として見せる。
- 音量は相対値(dB差)。大きい・小さいの絶対値ではない。
- 2026-11-13 より前の解析には、`timeline` と `ear_parts` がない。無いときは、その表示を出さない。
