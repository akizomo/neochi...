# フリーミアムの線引き(案)

2026-11-16 の議論で決めた方針。価格・トライアル期間・実装の順番は未定。

プレミアムは一言で「Player が賢くなる」。本編から静かに始まり、再生中は寝落ちしやすいあたりが見え、自分に合う番組が並ぶ。

## 原則

1. **データを生む行動は、すべて無料。** 寝落ちの記録(ヘルスケア)、みんなの評価、朝の振り返りは、総合評点と格付けの材料になる。ここを有料にすると、みんな10件・実測3件の基準(`SCORE.md`)に届かなくなる。
2. **みんなの答えは無料、「自分の場合」は有料。** 番組の評点・格付け・分析の詳細は、サイトと同じく無料。自分の記録から導いた解釈と最適化を有料にする。
3. **ユーザーごとに原価が出るものは有料。** その人のために LLM を呼ぶもの(パーソナライズ、解析のリクエスト)。

## 範囲

| | 無料 | プレミアム |
|---|---|---|
| 探す | 一覧、総合評点、Z/ZZ/ZZZ、系統の棚、今夜の1本(全員共通) | AI のパーソナライズ。自分の寝落ちの実績から「あなたが眠れる番組」を並べる |
| 聴く | 普通の再生、スリープタイマー | 本編から始める(下記)、Player の寝落ちグラフ(下記) |
| 回の詳細 | 起伏・話す速さ・音量・突発音の静的なグラフ(`SCORE.md` §6 の仕様のまま) | — |
| 記録 | 寝落ちの記録、寝落ちまでの分数、朝の振り返り、直近の履歴 | 全期間の傾向(`BACKLOG.md` の記録タブ)、書き出し |
| 解析 | 解析済みの番組を見る | 番組・回の解析リクエスト(月◯本まで)。結果は全員に公開する |

## 本編から始める

冒頭のジングル・告知・広告を飛ばし、ストレスなく聴き始められるようにする。打ち出しは「広告スキップ」ではなく「静かに始める」。

- **検出:** 解析の判定で、本編が始まる位置を一緒に出す(文字起こしの最初の一言+秒)。実装済み: `content_start`(`config/rubric.md`)→ analysis の `content_start_sec` / `content_start_anchor`(`0009_content_start.sql`)。冒頭5分に本編が見つからなければ null で、アプリは飛ばさない。音量の山(ジングル)も手がかりにする。RSS にチャプターがあれば優先する。
- **位置合わせ:** 動的広告挿入で、解析した音声と再生する音声の開始秒がずれる。秒ではなく本編の最初の一言を目印にし、端末内の音声認識で頭の数分を照合して位置を決める。
- **照合できないとき:** 飛ばさない。冒頭の大きな音を抑えて(音量の平準化)静かに入る。本編を誤って飛ばすほうがストレスになる。
- **お試し:** 無料でも毎晩1回だけ使える、を候補にする。

## Player の寝落ちグラフ

番組の起伏(`calm_per_min`)・話す速さ・音量を、再生位置と連動して出し、寝落ちしやすいエリアを帯で重ねる。タップでその位置へ移動できる。

寝落ちしやすいエリアの出どころは、データの量で切り替える。

1. 実測が少ないうち: 起伏・音量・話速が落ち着いた区間を「AIの推定」として出す。
2. 実測がたまったら: ウォッチの実測の寝落ち位置(再生開始から何分か)を回ごとに集め、「みんなが寝落ちしたあたり」の分布にする。
3. 自分の過去の寝落ち位置と、自分の傾向からの予測を重ねる。

無料の回の詳細のグラフ(静的)とは、再生位置との連動・寝落ちエリア・自分の記録の有無で分ける。

## 決めること

- 解析の範囲は冒頭20〜30分。グラフの後半(解析していない部分)の見せ方。
- ウォッチがない人の扱い(朝の振り返りの自己申告で寝落ち位置を代わりにするか)。
- パーソナライズを出し始める記録の件数(少ないうちは「あと◯晩」と示す)と、トライアルを始めるきっかけ。
- 価格(月額・年額・買い切り)。
