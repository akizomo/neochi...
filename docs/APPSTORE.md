## 3. 文面

### プロモーション用テキスト(170字まで)

眠りたい夜に聴く番組を、解析で選べます。話す速さ、音量、起伏、興味の度合いを調べて、寝落ちに向く番組を Z・ZZ・ZZZ の3段階で並べています。

### 説明文

眠りたい夜に、聴く番組を選ぶためのアプリです。

NeochiPickzz は、ポッドキャストの番組と話を解析して、寝落ちに向くかどうかを評点にします。

【こんなことができます】
・今夜の1本: 昨夜の結果と好みから、今夜聴く話を提案します
・見つける: 総合でいちばん評点の高い番組、寝落ち用の上位、ふだんの番組なのに眠れる番組を、一覧で見られます
・評点の中身: 起伏の少なさ、耳のゆるさ、程よい興味。どの観点がなぜその点なのかを、グラフと一言で確かめられます
・夜の再生画面: 番組の画像と時間だけの、静かな画面。15秒の戻し・送り、スリープタイマーつき
・寝落ちの記録: ヘルスケアの睡眠データから、再生を始めてから眠るまでの分数を記録します(許可した場合のみ。読み取りだけです)
・朝の振り返り: 評価と、覚えている範囲の自己申告を、選択肢で答えられます

【寝落ち格付け】
番組の評点で、Z・ZZ・ZZZ の3段階に分けています。基準に届かない番組は、掲載しません。評点は、AI解析を土台に、ヘルスケアの実測とみんなの評価が集まるほど、それらを足したものになります。

【大切なお知らせ】
・評点は、眠りを妨げる要素が少ないかの推定です。眠れることを保証するものではありません。
・医療機器ではなく、健康状態の判断や治療のためのものではありません。
・ヘルスケアのデータは、寝落ちまでの時間の記録にだけ使います。広告や第三者への提供には使いません。
・アカウント登録は要りません。記録は、設定からいつでも削除できます。
・番組の音声と画像の権利は、各配信元にあります。音声は配信元のサーバーから直接再生します。

## 4. App のプライバシー(栄養表示)

`ios/App/PrivacyInfo.xcprivacy` と同じ内容。追跡(トラッキング)はしない。すべて「ユーザーに紐づく」、目的は「App の機能」。

| データの種類 | 中身 | 紐づけ | 追跡 | 目的 |
|---|---|---|---|---|
| 健康とフィットネス → 健康 | ヘルスケアの睡眠データ(読み取りのみ。眠った時刻) | する | しない | App の機能 |
| 識別子 → ユーザ ID | 匿名のユーザー ID(Supabase の匿名ログイン。氏名・メール・IDFA は使わない) | する | しない | App の機能 |
| ユーザコンテンツ → その他 | 朝の振り返りのメモ | する | しない | App の機能 |
| 使用状況データ → 製品の操作 | 聴いた番組と話、再生の時刻、評価 | する | しない | App の機能 |

「連絡先情報」「位置情報」「購入」「診断」「広告データ」は、収集しない。サードパーティの SDK は入れていない(Supabase へは REST を直接呼ぶ)。

## 5. 審査へのメモ(App Review Information)

```
ログインは要りません。起動すると、匿名で使えます(アカウント画面や課金はありません)。

動作の確かめ方:
1. 起動後のオンボーディング(アプリの紹介 → 評点のしくみ → 好みのジャンル → 気になる番組 → ヘルスケアの説明)を「次へ」で進めてください。ヘルスケアの説明の「次へ」で、システムの許可画面が出ます(許可しなくても使えます)。
   続けて「どんな番組が好きですか」と聞かれたら、好きなものを選んで「決める」か、「あとで」を押してください(最初に出す番組の選び方に使います)。
2. 「見つける」で番組を選び、「いま聴く」で再生できます。夜の再生画面に、番組の画像・時間・15秒の戻しと送り・スリープタイマーがあります。
3. 「記録」タブで、記録の一覧が見られます。「設定」タブに、「記録をすべて削除」(アプリ内のデータ削除)があります。

・睡眠データの読み取りだけを要求します(書き込みはしません)。

番組は、配信元が公開している RSS フィードの情報です。音声は配信元のサーバーから直接再生し、アプリ内に複製・保存しません。各番組から、配信元のページへ移動できます。

評点は、眠りを妨げる要素が少ないかの推定で、医療や健康の判定ではありません(画面にも、その旨を書いています)。
```

## 8. リスクと注意

- **番組の画像・名前(5.2 の第三者コンテンツ):** 配信元が公開した RSS の情報を表示している。審査で権利の確認を求められたら、「公開フィードの情報を、出典を示して表示している。音声は配信元で再生される」と答える。申し出があれば、掲載を外す窓口(プライバシーポリシーの連絡先)がある。
- **ヘルスケアの表現:** 「改善」「効果」「睡眠の質」などの語は使っていない(`VOICE.md`、`tests/test_strings.py` が検査)。説明文を直すときも、入れない。
- **医療の位置づけ:** 説明文と画面の両方に、「医療機器ではない」と書いている。
- **審査で聞かれやすい点:** 「ヘルスケアのデータをなぜ読むのか」(上の審査メモに答えがある)、「バックグラウンドで音声を再生する理由」(夜に画面を閉じても眠るまで聴くため。`UIBackgroundModes: audio`)。
